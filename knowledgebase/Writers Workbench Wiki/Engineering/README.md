# Writers Workbench Wiki

The LLM-maintained knowledge base for this project. Entry point: [[overview]].

The schema is in [[CLAUDE]]. The catalog is in [[index]]. The log of changes is in [[log]].

To query the wiki via Claude Code, the obsidian-vault MCP must be approved (configured in `.mcp.json` at the project root). Two slash commands are available:

- `/challenge-obsidian` — pressure-test the current conversation against this vault.
- `/save-obsidian` — persist conversation insights into this vault per [[CLAUDE]] schema.
